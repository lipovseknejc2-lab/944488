# Atoll Angler

A fishing game set in the Maldives, made for playing upright on a phone.

**Play:** https://lipovseknejc2-lab.github.io/944488/atoll-angler/

## Add it to your iPhone home screen
1. Open the link above in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open Atoll Angler from the home screen. It runs full screen and works offline after the first launch.

## Saving
- Progress saves automatically, is checked for damage each time, and keeps a second copy plus 3 rotating backups.
- Menu > Save shows the save status and lets you restore a backup.
- Moving devices: Menu > Copy backup code, then paste it on the other device.

This folder is self-contained. Its offline worker only handles files inside `atoll-angler/`, so it does not affect the Grady app in the same repository.
