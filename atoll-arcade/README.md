# Atoll Arcade

Eight mini-games in one tropical arcade, made for playing upright on a phone: Reef Rush, Storm Pilot, Coconut Stack, Tide Match, River Path, Shell 2048, Island Sudoku and Shell Memory.

**Play:** https://lipovseknejc2-lab.github.io/944488/atoll-arcade/

## Add it to your iPhone home screen
1. Open the link above in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open Atoll Arcade from the home screen. It runs full screen and works offline after the first launch.

Progress (coins, levels, stars, stickers, best scores) saves automatically on the device.
This folder is self-contained. Its offline worker only handles files inside `atoll-arcade/`, so it does not affect the other apps in this repository.
